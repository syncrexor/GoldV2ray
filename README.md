## 📖 About Gold V2ray

Gold V2ray is a modern V2ray VPN client, built for speed, security, and total user control. Whether you need to bypass restrictions, ensure online privacy, or run a custom VPN business, Gold V2ray is the all-in-one solution you've been looking for.

### 🌟 Main Features
* **Free Global Servers:** Connect easily with our regularly updated list of fast, free servers.
* **Smart Connection:** Smart Connection automatically connects you to the fastest or least-traffic server in your selected group.
* **Smart Server Categories:** Sort servers into Wi-Fi, SIM, and SIM 2 for faster access and better organization.
* **Lock Mode for Custom Servers:** Secure your configurations and prevent unauthorized changes, especially useful on shared devices.
* **Store Mode for Business:** Perfect for resellers and commercial VPN providers. Customize the interface and lock all settings.
* **Advanced Speed Test with Scores:** Instantly measure and compare server performance to find the fastest connection.
* **Light and Dark Mode Support:** Choose between bright or dark themes, fully integrated with your system settings.
* **Automatic Geo File Updates:** Keep your routing rules and region data always up-to-date without any manual effort.

### ❓ Why Choose Gold V2ray?
Unlike basic VPN apps, Gold V2ray combines a powerful backend with a modern UI and pro-level tools. Built on the trusted V2rayNG core and open-sourced for maximum transparency and performance.

### 🎯 Ideal For:
* Users in restricted networks (schools, offices, or countries with firewalls).
* Businesses offering branded VPN services.
* Advanced users looking for fine-tuned control.
* Everyday users who want speed, security, and simplicity.
* Gold V2ray supports popular protocols including V2Ray, Shadowsocks, and WireGuard.
* Experience a secure, private, and lightning-fast internet connection—free and open source.
