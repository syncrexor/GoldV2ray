## 📖 关于 Gold V2ray

Gold V2ray 是一款现代化的 V2ray VPN 客户端，专为速度、安全和全面控制而设计。无论您需要绕过限制、确保在线隐私，还是运营自定义 VPN 业务，Gold V2ray 都是您一直在寻找的一站式解决方案。

### 🌟 主要功能
* **免费全球服务器：** 轻松连接到我们定期更新的快速免费服务器列表。
* **智能连接：** 自动连接到您所选组中最快或流量最少的服务器。
* **智能服务器分类：** 将服务器分类为 Wi-Fi、SIM 1 和 SIM 2，以便更快地访问和更好的组织。
* **配置锁定模式：** 保护您的配置并防止未经授权的更改，这在共享设备上特别有用。
* **商业商店模式：** 非常适合经销商和商业 VPN 提供商。自定义界面并锁定所有设置。
* **带分数的高级速度测试：** 即时测量和比较服务器性能以找到最快的连接。
* **浅色和深色模式支持：** 与您的系统设置完全集成。
* **自动更新 Geo 文件：** 始终保持您的路由规则和区域数据为最新，无需任何手动操作。

### ❓ 为什么选择 Gold V2ray？
与基本的 VPN 应用程序不同，Gold V2ray 结合了强大的后端与现代化的 UI 和专业级工具。它基于值得信赖的 v2rayNG 核心构建，开源以实现最大的透明度和性能。

### 🎯 适用人群：
* 受限网络中的用户（学校、办公室或有防火墙的国家/地区）。
* 提供品牌 VPN 服务的企业。
* 寻求精细控制的高级用户。
* 支持包括 V2Ray、Shadowsocks 和 WireGuard 在内的流行协议。
